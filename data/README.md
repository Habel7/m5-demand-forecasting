# Data

The M5 dataset is not committed to this repo (~450 MB).

Download from Kaggle (requires a free account):
https://www.kaggle.com/competitions/m5-forecasting-accuracy/data

Or via the Kaggle CLI:

    kaggle competitions download -c m5-forecasting-accuracy -p data/
    unzip data/m5-forecasting-accuracy.zip -d data/

Files expected here:
- calendar.csv
- sales_train_validation.csv
- sales_train_evaluation.csv
- sell_prices.csv
